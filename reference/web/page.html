Cab IR Capture

Record the test sweeps in Logic, drop the recordings here, and download finished impulse responses at every sample rate and length. Everything runs in this page; nothing is uploaded.

Record TONE3000's training signal through the amp in Logic, drop the recordings here, and get files lined up to the sample and cut to the exact length, ready to upload for NAM training. Everything runs in this page.

1

Test signal

Pick the sample rate your Logic project will run at. All the other rates are made from this one capture, so use the highest your interface does well.

Sweep timing

The gap has to be longer than the room's reverb tail. The first sweep is a warm-up and isn't used. More sweeps lower the noise floor by about 3 dB each time you double them.

Keep these settings when you process the recording in step 3. This page remembers them.

2

Record in Logic

  1. Set the Logic project to the capture rate above. Unzip the download and drag the sweep WAV onto a new audio track at bar 1.
  2. Send that track only to the interface output that feeds the power amp. Mute the studio monitors so the room mic doesn't hear them.
  3. Make one audio track per mic and one for the reference tap if you have it. Name each track after its mic (SM57, R121, Room…) and name the reference track “Ref”; the exported files take these names. Record-enable them all, with input monitoring off and no plug-ins.
  4. Play the sweep track and watch the meters. Set each mic preamp so the loudest point of the sweep peaks around −6 dBFS. Nothing should clip.
  5. Record one full pass, about the length shown in step 1. Keep the room quiet and don't touch the mics.
  6. Choose File › Export › All Tracks as Audio Files. Pick WAV, 24-bit or 32-bit float, at the project sample rate, with Normalize off, and note which folder it saves to. Leave the faders at 0 dB.

Reference tap (recommended)

Pad the voltage across the speaker terminals by about 20 dB (for example 10 kΩ in series, 1.1 kΩ to ground) and record it on its own line input. The IRs then come out as speaker, mic and room only, whatever power amp you use, and the interface latency cancels.

If the amp's speaker output is bridged (neither terminal is ground), or the tap brings in hum, use an isolation transformer or a balanced input. Without a reference the IRs still work, but they include the power amp's own response.

3

Make the IRs

  1. In Finder, open the folder Logic exported to. You'll see one WAV per track, named after the Logic tracks.
  2. Select the mic files and the reference file, then drag them onto the box below, or click the box and pick them. If the sweep track's file comes along too, that's fine; it's skipped automatically.
  3. Check the list that appears. Each mic needs a short name (it goes into the IR file names), and the reference file should say “Reference tap”.
  4. Type a capture name for this cab and mic position, then click Make IRs.

    1

    Training signal

    1. Log in at tone3000.com. Choose Create Tone, then Capture, and download the sweep file. It's called T3K-sweep-v3.wav (190 seconds, 48 kHz).
    2. Use that file exactly as it is. Don't trim, normalize or convert it. This page knows its layout, so you don't need to give it the file.
    2

    Record in Logic

    1. Make a new Logic project at 48 kHz. Drag T3K-sweep-v3.wav onto an audio track at bar 1.
    2. Send that track to the interface output that goes to the reamp box, and the reamp box into the amp's input. Turn off noise gates, reverb, delay and anything in the effects loop.
    3. Amp only: speaker output into the load box (the Suhr Reactive Load), and its line out into an interface input. Leave any cab sim or EQ on the load box off.
      Full chain: amp into the cab as usual, with mics on the cab. Mute the studio monitors.
    4. Make one audio track per input and name it (Suhr, SM57, R121…); the exported files take these names. Input monitoring off, no plug-ins.
    5. Set the reamp level so the amp is hit about as hard as by a guitar. Play the first 20 seconds and set each input so the loudest part peaks around −8 dBFS, with nothing clipping.
    6. Warm the amp up for about 20 minutes first. Then record one full pass, all 3 minutes 10 seconds, and a second or two past the end. Don't touch any knobs while it runs.
    7. Choose File › Export › All Tracks as Audio Files: WAV, 24-bit, 48 kHz, Normalize off.

    Which model to make

    Amp only is the flexible one: pair the model with this tool's cab IRs. Use IRs captured with the speaker-terminal reference tap. The load box's line out already carries the speaker's impedance bump, so a sweep-referenced IR would add it twice.

    Full chain captures amp, cab and mic together. Each mic becomes its own model. Close mics work best: NAM only models a short stretch of time, so room sound won't carry over well.

      ChannelPeakNoiseStart vs endLined up
      1. Save the zip above and double-click it in Finder to unzip it. It holds one WAV per channel, plus the report and these steps.
      2. At tone3000.com/capture, upload the WAV files, one model per file.
      3. Settings: Model Standard, Best Fit on, 400 max epochs (TONE3000's suggestion). Name each model with the amp, its knob settings and, for mics, the mic and its position. Keep it private unless you mean to share it.
      4. Training takes about 5–20 minutes. Check the ESR when it's done: under 0.01 is great; 0.3 or more means something went wrong. Download the .nam file to use in any NAM player.

      “Start vs end” compares the opening 9 seconds of the take with the closing 9, which are the same signal. It shows how much the amp drifted while you recorded, and a model can't be much more accurate than that. Under 0.001 is excellent.

      Method: exponential sine sweeps (Farina), averaged, with harmonic distortion windowed out. With a reference tap each IR is the speaker-terminal voltage to microphone response. Version __VERSION__.
